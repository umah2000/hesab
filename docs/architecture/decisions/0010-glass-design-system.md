# ADR-0010: سیستم طراحی شیشه‌ای (Glass 2026)

**وضعیت:** پذیرفته · ۱۴۰۵/۰۷/۱۹ (ظاهر توسط مالک محصول تأیید شد)

## زمینه
مالک محصول ظاهر گلس‌مورفیسم را خواسته است. نرم‌افزار ساعت‌ها پشت صندوق و در محیط اداری استفاده می‌شود. سخت‌افزار مشتری اول ضعیف است (Core i3، ۴GB RAM). `backdrop-filter` روی GPU ضعیف هزینه دارد و شیشه پشت متن متراکم خوانایی را کم می‌کند.

## تصمیم
- شیشه فقط برای قاب‌ها (sidebar، header، کارت، دیالوگ)؛ داده متراکم روی سطح تقریباً مات.
- «حالت سبک» در سطح هر دستگاه (localStorage) که blur را حذف می‌کند. این حالت برای صندوق‌ها توصیه می‌شود.
- رعایت `prefers-reduced-transparency` و `prefers-reduced-motion`.
- Tailwind v4 با توکن‌های OKLCH؛ مؤلفه‌ها به سبک shadcn/ui روی Radix.
- فونت وزیرمتن self-hosted. هیچ منبع CDN استفاده نمی‌شود.
- حالت روشن و تیره.

## پیامدها
+ ظاهر مطابق سلیقه مالک محصول، بدون قربانی‌کردن خوانایی.
+ روی سخت‌افزار ضعیف قابل استفاده با حالت سبک.
− باید روی سیستم واقعی صندوق (i3) آزموده شود که حالت شیشه‌ای روان است یا حالت سبک پیش‌فرض صندوق شود (فاز ۴).
