# ADR-0003: استقرار تک‌مستأجر

**وضعیت:** پذیرفته · ۱۴۰۵/۰۷/۱۹

## تصمیم
هر مشتری (سازمان) یک نصب Backend و یک دیتابیس مستقل دارد. ستون `tenant_id` وجود ندارد. جدول `organization` دقیقاً یک رکورد دارد. یک سازمان می‌تواند چند **شعبه** داشته باشد؛ جداسازی داده بین شعب با `branch_id` و محدوده دسترسی کاربر انجام می‌شود.

## پیامدها
+ جداسازی کامل داده مشتریان؛ Backup/Restore هر مشتری مستقل.
+ کوئری‌ها و Indexها ساده‌تر.
− به‌روزرسانی هر نصب جداگانه است؛ فاز ۱۰ باید فرایند به‌روزرسانی امن (Backup ← Migration ← بررسی سلامت) داشته باشد.
− ارائه SaaS چندمستأجره در آینده نیازمند ADR جدید است.
