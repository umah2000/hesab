# مجوز نرم‌افزار و فعال‌سازی

تصمیم‌ها: [ADR-0021](../architecture/decisions/0021-license-activation.md). سیاست تجاری (سقف‌ها و مدت): Q25.

> مجوز **هیچ‌وقت** این‌ها را متوقف نمی‌کند: فروش، ورود کاربران، گزارش‌ها، پشتیبان‌گیری و صندوق آفلاین.
> فقط بر **افزودن** شعبه، صندوق، کاربر و ویزیتور بالاتر از سقف اثر دارد.

## برای مدیر فروشگاه
1. «تنظیمات ← مجوز نرم‌افزار»: **کد درخواست** (`NCR1.…`) را با دکمه‌ی «کپی» بردارید و برای فروشنده بفرستید.
2. متن مجوزی را که فروشنده می‌فرستد (`NCL1.…`) در همان کادر بچسبانید و «نصب مجوز» را بزنید. شکستگی خط در متن ایمیل مشکلی ندارد.
3. وضعیت، تاریخ اعتبار، سقف‌ها و میزان استفاده همان‌جا دیده می‌شود. از ۳۰ روز پیش از پایان اعتبار، در داشبورد مدیر هشدار نمایش داده می‌شود.

| وضعیت | معنا |
|---|---|
| بدون مجوز | هنوز مجوز نصب نشده؛ همه‌چیز بدون سقف کار می‌کند (فقط هشدار) |
| معتبر | مجوز درست است |
| رو به پایان | کمتر از ۳۰ روز تا پایان اعتبار |
| منقضی | اعتبار تمام شده؛ کار ادامه دارد، ولی هشدار نمایش داده می‌شود |
| نامعتبر | امضای مجوز دیگر پذیرفته نیست؛ با فروشنده تماس بگیرید |

بازیابی سرور از پشتیبان یا جابه‌جایی سرور، **فعال‌سازی دوباره نمی‌خواهد**؛ شناسه‌ی نصب در خود دیتابیس است.

## برای فروشنده (یک بار، روی رایانه‌ی خودتان — نه سرور مشتری)
```powershell
pip install cryptography
python tools\license\nextcam_license.py keygen --out D:\vault\nextcam-signing.pem
```
- **کلید خصوصی:** با گذرواژه (حداقل ۱۲ نویسه) رمزنگاری می‌شود. فایل و گذرواژه را جدا و آفلاین نگه دارید و یک نسخه‌ی پشتیبان داشته باشید.
- **کلید عمومی:** خط چاپ‌شده را در `backend/app/modules/system/license_keys.py` (فهرست `TRUSTED`) بگذارید و نسخه‌ی جدید منتشر کنید. کلید عمومی محرمانه نیست.

## صدور مجوز برای هر مشتری
```powershell
python tools\license\nextcam_license.py sign --key D:\vault\nextcam-signing.pem `
  --request NCR1.eyJ... --branches 1 --registers 7 --users 25 `
  --valid-until 2027-10-19 --support-until 2027-10-19 --feature distribution --out store.nclic
python tools\license\nextcam_license.py show store.nclic
```
- **سقف نامحدود:** هر سقفی را که ندهید نامحدود است.
- **مجوز دائمی:** بدون `--valid-until`.
- **تمدید یا افزایش سقف:** مجوز تازه با همان کد درخواست صادر کنید. مجوز تازه جای قبلی را می‌گیرد.
