# رجیستری سازگاری سخت‌افزار

> وضعیت‌ها: `Verified` (آزموده روی خود دستگاه، با شواهد) · `Conditionally Supported` · `Not Verified` · `Unsupported`.
> **هیچ دستگاهی تا آزمون روی مدل واقعی `Verified` نمی‌شود.** آزمون پروتکل یا شبیه‌ساز شاهد سازگاری نیست.

## آزمون‌های پروتکل انجام‌شده (۱۴۰۵/۰۷/۲۳)
- **چاپ فیش، کامل:** سرور ← صف ← Agent ← چاپگر شبکه‌ی جعلی (سوکت TCP روی ۹۱۰۰ در همان رایانه).
  - بایت‌های دریافت‌شده با کدگشای `GS v 0` دوباره به تصویر تبدیل شدند: [`70-agent-receipt-escpos-decoded.png`](../design/screenshots/70-agent-receipt-escpos-decoded.png) و [`71-agent-test-page-escpos-decoded.png`](../design/screenshots/71-agent-test-page-escpos-decoded.png).
  - ترتیب بایت‌ها بررسی شد: `ESC @`، سپس `ESC p 0 25 250` (کشو، فقط فاکتور نقدی)، تصویر، `ESC d 4`، سپس `GS V 66 0`.
- **کشو بدون فروش:** کار ۷ بایتی `ESC @ ESC p 0 25 250`.
- **تست‌های خودکار:** ۱۳ تست در `device-agent/tests`، شامل:
  - رفت‌وبرگشت تصویر و تقسیم به نوارها؛
  - رساندن دقیق بایت‌ها از TCP؛
  - اجرای یک‌باره‌ی هر کار؛
  - گزارش خطای چاپگر؛
  - API وضعیت فقط‌خواندنی با رد Host و Origin نامعتبر.

## پیش از تأیید هر مدل (چک‌لیست)
1. برند، مدل، Firmware، نوع اتصال؛ برای USB، نام چاپگر در ویندوز و درایور.
2. چاپ صفحه‌ی آزمایشی از صفحه‌ی «دستگاه‌های صندوق»: متن فارسی خوانا، راست‌چین، بدون برش ناقص.
3. فاکتور واقعی ۸۰ و ۵۸ میلی‌متری با ۳۰ قلم (فیش بلند، چند نوار تصویر).
4. کشو: باز شدن با فروش نقدی؛ باز نشدن با کارت و چاپ مجدد؛ پایه ۲ یا ۵.
5. خطاها: کاغذ تمام، درب باز، کابل شبکه یا USB جدا، خاموش بودن. پیام صندوق‌دار و رفتار «چاپ با مرورگر».
6. ری‌استارت ویندوز: سرویس Agent خودکار بالا می‌آید و دوباره وصل می‌شود.
7. ثبت نتیجه، تاریخ، نسخه‌ی Agent و عکس فیش در همین جدول.
